# Лабораторная работа №2 — Временные ряды

## Трудности

Возникли трудности с качеством исходного Excel-файла: часть рабочих листов была скрыта, названия листов и городов местами были повреждены кодировкой, встречались опечатки, дубли, смешанные типы данных и выбросы. Дополнительно нужно было аккуратно восстановить единый временной индекс и привести все ряды к согласованному формату, чтобы затем корректно построить признаки и обучить модели многошагового прогноза.

## Описание
В работе выполнено восстановление и очистка данных из Excel-файла с ошибками ручного ввода, скрытыми листами, пропусками, выбросами и несогласованным оформлением.  
После обработки был получен многомерный временной ряд погоды по нескольким городам

Цель работы - построить модели для **многошагового прогноза температуры на 1 неделю вперёд**

## Что сделано
- получен доступ ко всем листам Excel, включая скрытые;
- очищены и унифицированы данные;
- восстановлен единый временной индекс;
- обработаны пропуски, дубли и выбросы;
- проведён анализ временного ряда:
  - визуализация,
  - проверка стационарности,
  - STL-декомпозиция,
  - спектральный анализ;
- построены признаки для прогнозирования;
- обучены модели:
  - дерево решений,
  - случайный лес,
  - градиентный бустинг;
- выполнен подбор гиперпараметров через Optuna;
- реализованы стратегии:
  - **direct** — отдельная модель на каждый горизонт;
  - **recursive** — рекурсивный прогноз по одной одношаговой модели;
- проведено сравнение моделей по метрикам качества

## Используемые метрики
- MAE
- WAPE
- MAPE
- Directional Accuracy
- Directional R²
